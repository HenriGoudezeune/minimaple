mini-Maple voor Windows

Dezelfde worksheet als op maple.hydrargyrum.be, maar als app op je eigen laptop. De rekenkern draait lokaal: geen internet nodig, geen tijdslimiet van de server, en je kan .mw- en .mpl-bestanden rechtstreeks openen met een dubbelklik.

Download voor Windows (.zip)
Versie2026.11.26
Grootte99 MB (uitgepakt 284 MB)
SysteemWindows 10/11, 64-bit
InstallatieGeen admin nodig

Inclusief eigen Python en alle rekenbibliotheken. Broncode: github.com/HenriGoudezeune/minimaple.

Installeren

  1. Download de zip en pak hem uit naar een vaste map, bijvoorbeeld C:\Users\jij\mini-Maple (rechtsklik → Alles uitpakken).
  2. Dubbelklik mini-Maple.vbs. De app opent in een eigen venster.
  3. Optioneel: dubbelklik snelkoppeling-maken.vbs voor een snelkoppeling op het bureaublad en in het Startmenu.

Windows waarschuwt bij de eerste start

De app is niet digitaal ondertekend (dat kost honderden euro's per jaar). Windows SmartScreen toont daarom "Windows heeft uw pc beveiligd". Klik op Meer informatie → Toch uitvoeren. Blokkeert Windows de scripts, rechtsklik dan de zip vóór het uitpakken → Eigenschappen → vink Blokkering opheffen aan.

mini-Maple als standaard voor .mw en .mpl

  1. Dubbelklik bestandskoppeling-aan.vbs in de map van de app.
  2. Windows laat een app de standaard niet stil overnemen. Rechtsklik daarom één keer een .mw-bestand → Openen met → Een andere app kiezen → mini-Maple → Altijd. Doe hetzelfde voor een .mpl-bestand.
  3. Of via Instellingen → Apps → Standaard-apps → mini-Maple.

Ongedaan maken: bestandskoppeling-uit.vbs.

Gebruik

  • Enter voert een invoergroep uit, Shift+Enter geeft een nieuwe regel.
  • Ctrl+J / Ctrl+K: nieuwe invoergroep eronder / erboven.
  • Ctrl+Space: autocompletion, F1 of ?diff: help.
  • Werkt het venster niet, start dan mini-Maple.bat: dat toont de foutmelding.

Bijwerken en verwijderen

  • Bijwerken: download de nieuwe zip en pak hem uit over de oude map.
  • Verwijderen: draai bestandskoppeling-uit.vbs, verwijder de snelkoppelingen en daarna de map. Er blijft niets achter in het register.
